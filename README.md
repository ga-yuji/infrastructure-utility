English

MENU - Infrastructure utilities

I created this project to help answer common questions that arise during the day for an infrastructure analyst. Currently at version 1.0,
it includes only two working features: an IP calculator that computes the subnet range and returns complete information about the provided subnet, and a small scanner to check which ports are open.
