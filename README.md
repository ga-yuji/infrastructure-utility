MENU - Infrastructure utilities

Pensei em elaborar este projeto com um intuíto de facilitar a resposta para algumas questões que aparecem ao longo do dia para um analista de infraestrutura, até o momento na versão 1.0,
possui apenas 2 funções funcionando, sendo a calculadora de IP, cujo calcula o barramento da subnet retornando informações completa sobre a porção de subnet passada e um pequeno scan para checar
quais portas estão abertas.
